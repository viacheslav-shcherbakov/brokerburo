# BrokerBuro — Персональное брокерское бюро Вячеслава Щербакова

Веб-сайт персонального брокерского бюро для покупки, продажи и сопровождения сложных сделок с недвижимостью в Москве.

## Описание

BrokerBuro — это профессиональное брокерское бюро, специализирующееся на сложных сделках с недвижимостью. Руководитель бюро — Вячеслав Щербаков, кандидат юридических наук с 15-летним опытом практики.

## Структура проекта

```
├── index.html              # Главная страница
├── blog.html               # Страница блога/заметок
├── cases.html              # Страница с кейсами
├── catalog.html            # Каталог объектов
├── coaching.html           # Страница коучинга
├── lawlikbez.html          # Страница юридической информации
├── object.html             # Страница объекта
├── assets/
│   ├── css/                # Стили
│   │   ├── style.css
│   │   ├── style-premium.css
│   │   └── style-v2.css
│   ├── js/                 # JavaScript файлы
│   │   ├── common.js
│   │   └── telegram-form.js
│   └── img/                # Изображения
└── data/                   # JSON данные
    ├── cases.json          # Данные кейсов
    ├── listings.json       # Данные объектов недвижимости
    └── posts.json          # Данные постов блога
```

## Технологии

- HTML5
- CSS3 (кастомные стили)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Inter)
- JSON для хранения данных

## Основные возможности

- Адаптивный дизайн с мобильной навигацией
- Динамическая загрузка объектов недвижимости из JSON
- Форма обратной связи с интеграцией Telegram
- Секции: объекты, кейсы, услуги, о бюро, блог
- SEO-оптимизированная разметка с Open Graph метатегами

## Установка и запуск

1. Клонируйте репозиторий или скопируйте файлы проекта
2. Откройте `index.html` в любом современном браузере

```bash
# Или используйте локальный сервер
python -m http.server 8000
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

## Требования

- Современный браузер с поддержкой HTML5, CSS3 и ES6+
- Для работы формы обратной связи требуется настройка Telegram Bot API
